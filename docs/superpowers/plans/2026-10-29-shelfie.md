# Shelfie Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code plugin that automatically logs the artifacts Claude makes in a project (claude.ai pages, files, local servers) into `<project>/.shelfie/`, asks Claude once per item per session for a description / change note, and renders a static read-only dashboard.

**Architecture:** Hooks (`SessionStart`, `UserPromptSubmit`, `PostToolUse`, `Stop`) call one Python CLI (`bin/shelfie`) that records *candidates* into a JSON registry; the `Stop` hook blocks once to ask Claude to classify/describe pending items via `.shelfie/bin/shelfie note …`; every registry write re-renders `.shelfie/shelfie.html` from a self-contained template with the data embedded.

**Tech Stack:** Python 3.9+ standard library only (stock macOS `python3`), `unittest`, vanilla HTML/CSS/JS, Claude Code plugin + marketplace manifests.

**Spec:** `docs/superpowers/specs/2026-10-29-shelfie-design.md` (visual reference: `docs/design/dashboard-mockup.html`)

## Global Constraints

- Python 3.9 compatible (`from __future__ import annotations`; no `match`, no runtime `X | Y`). Stdlib only, no pip.
- All state in `<project>/.shelfie/`; never write into the plugin dir. Sole exception: one consented allow rule merged into `<project>/.claude/settings.local.json`.
- Project root = env `CLAUDE_PROJECT_DIR` (fallback: payload `cwd`).
- Hooks never break Claude: any exception → log to `.shelfie/errors.log`, exit 0, no output. Unconfigured project (no `config.json`) → hooks do nothing except `SessionStart`'s setup prompt.
- Capture window: a file counts only if its mtime falls inside the current turn (`UserPromptSubmit` → `Stop`).
- Ask Claude at most once per item per session; never block when `stop_hook_active` is true; ignored items are never asked about again.
- Types/labels/badges/colours exactly as the spec's table: `artifact` Claude artifact `#d97757` ARTIFACT · `html` HTML `#f76b15` HTML · `pdf` PDF `#e5484d` PDF · `md` Markdown grey MD · `doc` Doc `#3e63dd` DOCX · `slides` Slides `#e2a336` PPTX · `sheet` Sheet `#30a46c` XLSX · `server` Local server `#8e4ec6` SERVER · `image` Image `#12a594` IMG.
- Dashboard: English UI, static, no network requests, works from `file://`, light/dark via `prefers-color-scheme`, no horizontal scroll at 375px.
- Timestamps ISO-8601 with local offset (`datetime.now().astimezone().isoformat(timespec="seconds")`).

## Review Focus

1. **Malformed / unexpected hook input** (empty stdin, missing `tool_response`, unknown tool shape) → hook exits 0 silently, nothing recorded. Test in Task 7.
2. **Non-ASCII and spaces in paths and text** (Cyrillic file names, project dir with spaces) → stored and rendered intact. Tests in Task 1 and Task 6.
3. **Text that breaks the embedded JSON** (`</script>`, quotes, emoji in titles/descriptions) → page still parses and shows the text literally. Test in Task 6.
4. **Two sessions in the same project writing at once** → no lost entries, registry stays valid JSON. Test in Task 1.
5. **Big trees** (`node_modules`, venvs, thousands of files) → excluded / capped, scan stays fast. Test in Task 2.

## Shared data model (used by every task)

`.shelfie/config.json`:
```json
{"version": 1, "formats": ["artifact","html","pdf","md","doc","slides","sheet","server","image"], "exclude": []}
```
`.shelfie/registry.json`:
```json
{"version": 1, "entries": [ENTRY, ...]}
```
ENTRY:
```json
{"id": "k3f9a2", "type": "html", "status": "pending|artifact|ignored",
 "title": null, "description": null,
 "path": "reports/q4.html", "source_type": null, "url": null,
 "server": null, "files": null,
 "created_at": "...", "updated_at": "...",
 "changes": [{"at": "...", "note": "Created"}],
 "pending": {"kind": "new|changed", "session": "sid", "at": "..."},
 "noted_sessions": ["sid"]}
```
- `path`: project-relative POSIX path; for a group, the directory with trailing `/` and `files` = list of relative paths.
- `server`: `{"command": str, "cwd": str (project-relative, "." for root), "port": int|null}`.
- `source_type`: original file type when a file entry was merged into an `artifact`.
- Turn state: `.shelfie/state/turn-<session_id>.json` = `{"started_at": <epoch float>}`.
- Launcher: `.shelfie/bin/shelfie` (sh): `exec python3 "<abs plugin root>/bin/shelfie" "$@"`.
